# Результаты для организаторов

`dev/results.json` содержит 65 уникальных исходных DEV ID и 520 оценок в формате
Appendix Results 1.0. Это сохранённые ответы `gpt-6-luna` / prompt
`cqa-2026-11-07-v1`: 45 tune baseline и 20 holdout выбранной конфигурации.
Отвергнутый candidate v2 и человеческие ответы не использованы для заполнения.
Файл собран offline, без новых AI-вызовов; исходные оценки не менялись.

Каждый ID сопоставлен с исходным DEV по языку, каналу и всем репликам в исходном
порядке. Баллы повторно рассчитаны общей Decimal-функцией. Все восемь кодов
переведены в формат организаторов; evidence_turns нумеруются с 1 по полному
транскрипту, включая клиента, бота и системные события. Полные диапазоны раскрыты
включительно. Все 65 записей имеют status=ok; ошибок обработки нет.

status=ok означает завершённую структурно валидную оценку, а не подтверждённую
человеком правильность. В приватных источниках 22 оценки имеют review_reasons;
они не заменены эталоном и не скрыты как ошибки обработки. Известные ограничения
качества и четыре provisional-примечания человеческой разметки описаны в
[FINAL_RELEASE.md](../docs/FINAL_RELEASE.md).

В опубликованном JSON нет исходных транскриптов, аудиоссылок, ключей,
человеческой разметки и сырых ответов API. Обоснования взяты из сохранённых
AI-оценок; доказательства представлены только номерами реплик.

`prod/results.json` появится после выдачи организаторами отдельного контрольного
набора из 10 чатов и его фактической обработки. Пользователь подтвердил, что
контрольные чаты пока не выданы. Внутренние 20 holdout из DEV не являются PROD.

Команды воспроизведения и проверки — в [README](../README.md#результаты-для-сдачи).
