# Официальный контроль FBroker

`results.json` содержит все 10 контрольных чатов FBroker и 80 фактических
AI-оценок в формате Appendix Results 1.0. Организаторы выдали набор 2026-11-08;
это отдельный контроль, а не DEV или внутренний holdout.

Модель `gpt-6-luna`, prompt `cqa-2026-11-07-v1`, исходный чек-лист,
reasoning medium, max_output_tokens12000, timeout90s. Ровно 10 фактических
API-попыток без повторов: 10 completed, 0 failed; 4 RU, 4 KZ, 2 EN.
Файл сохраняет исходные ID, обоснования модели и номера доказательств с 1 по
полному транскрипту всех ролей. Баллы и N/A пересчитаны общей Decimal-функцией.

У четырёх оценок диалогов есть приватные review_reasons: status=ok означает завершённую
валидную обработку, а не подтверждённую человеком правильность. Эталонные
ответы организаторов неизвестны, точность на PROD не заявляется.

Дополнительный Swap сохранён отдельно: 3 записи, 0 оценок. Он не входит
в этот файл и ожидает дополнительной инструкции организаторов.

Фактический прогон и границы проверки — в [CONTROL_RELEASE](../../docs/CONTROL_RELEASE.md).
