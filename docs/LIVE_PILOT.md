## Ограничение попыток и стоимости

Использована временная оснастка `/tmp/cqa-live-single-pilot.py`, SHA256
`b516276128bed23ebc47bca97fe6b384399a0c39730b275579e51957ca62258f`.
Перед запуском отдельный `gpt-6.1-sol / xhigh` одобрил именно этот hash.
Реальный запуск выполнил только родительский интегратор; остальные агенты
использовали MockTransport или читали уже сохранённые синтетические результаты.

- Durable exclusive marker с fsync создаётся до единственного SDK-вызова.
  Ошибка, таймаут или повтор процесса не разрешают новую попытку.
- SDK/application/transport retries — 0; redirects отключены; base URL —
  официальный. Нет preflight-запросов, tools, response storage и dataset API.
- `service_tier=default`, `store=False`, `max_output_tokens=12000`.
- Полное HTTP body — 10 844 UTF-8 bytes. Консервативная верхняя оценка input:
  `4 × bytes + 4096 = 47472`. Предельное body — 64 000 bytes;
  оценка input не может превышать 272 000 tokens.
- Для бюджетного допуска использованы $0.125/M input и $0.50/M output,
  включая 10% региональную надбавку: bound этого запроса **$0.0131274**;
  максимально допустимого body — **$0.0423632**, ниже $0.10.

По фактическим usage и стандартным тарифам $0.10/M input, $0.50/M output
базовая оценка — **$0.0006135**, с 10% надбавкой — $0.00067485.
Это расчёт, а не проверенный счёт аккаунта. Тарифы и возможности модели
сверены с [официальной документацией OpenAI](https://developers.openai.com/api/docs/models/gpt-6-luna).
