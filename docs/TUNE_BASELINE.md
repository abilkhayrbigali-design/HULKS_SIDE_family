# Первый baseline: 45 tune — 2026-11-08

На предоставленной пользователем разметке `gpt-6-luna` совпала по применимости и
ответу в **319 из 360 критериев — 88.61%**. Средняя абсолютная ошибка итогового
балла — **7.2542 пункта /100** на 45 диалогах. Все 45 оценок технически завершены;
ошибочных или пропущенных запусков нет.

Это **результат на tune**, не независимая точность holdout и не официальный
результат организаторов. Промпт не подстраивался по этим результатам. У 20 holdout
предсказаний нет; четыре примечания ещё требуют человеческого согласования.

## Данные и фиксированная конфигурация

Проверены 65 диалогов / 520 ответов: 45 tune / 360 ответов и 20 holdout / 160.
Принято пользовательское подтверждение человеческого происхождения разметки;
автоматическая проверка подтверждает структуру, не смысловую правильность эталона.
Один неизменяемый снимок чек-листа; пересечений частей по case/conversation/
transcript IDs и точному хешу ролей/текстов не обнаружено. Исходные файлы, ответы,
примечания и состав выборок не менялись. Отпечатки сохранены только приватно.

Разрешение: D-022/BEN-01. Код приложения:
`fa301d36a33cdead3fee7c410d2d2ecdc03e7030`; последующие изменения — документация.
Requested/reported model: `gpt-6-luna`; prompt `cqa-2026-11-07-v1`; reasoning
`medium`, max_output_tokens `12000`, timeout `90s`, concurrency `2`, retries `0`.
Ровно **45 фактических API-попыток**, все с первого раза; повторных вызовов нет.

Каждый вызов обычного OpenAIProvider получил только зафиксированный транскрипт
и чек-лист, без человеческих ответов/объяснений/review notes. Responses API,
`store=false`, настоящий сетевой SDK, без MockTransport. До вызовов сохранены
frozen labels и manifest с checksum/configuration. Сравнение выполнено после
всего пакета штатным offline benchmark и повторено существующим CLI: JSON-отчёты
полностью совпали. Сохранены полные ProviderResult и usage, эталон не изменялся.

## Что требует разбора

Сохранён приватный список всех 41 расхождения. Оценки и промпт автоматически не
исправлялись: расхождение с пользовательским эталоном само по себе не доказывает,
какая интерпретация правил неверна.

- Выявление потребности: 12 расхождений, из них 10 — человеческий N/A против
  применимого ответа модели.
- Всего N/A-пропусков 13: ещё 2 у завершения и 1 у идентификации.
- Грубые нарушения: один false negative; его нужно проверить до заявлений о
  достаточном качестве обнаружения риска.
- Высокий MAE в трёх звонках требует просмотра этих tune-расхождений человеком,
  но объём недостаточен для общей оценки канала.

Следующий этап — человеческий разбор tune, решение о версии промпта/правил и
отдельная фиксация конфигурации. Новый платный прогон, смена модели или изменение
эталона этим отчётом не разрешаются. Holdout согласуется без просмотра predictions;
до финальной проверки его состав и ответы не подгоняются под модель.

## Воспроизведение и приватность

Однократный платный runner `/tmp/cqa_tune_baseline.py --live-tune` завершён и
не является командой новой установки. Повторять его для пересчёта отчёта не нужно.
Для offline-пересчёта существующим инструментом:

```bash
uv run --project backend --locked python tools/evaluate_dev.py \
  --labels data/private/<run>/labels.frozen.json \
  --predictions data/private/<run>/predictions.json --split tune \
  > data/private/<run>/benchmark.recomputed.json
```

`<run>` — каталог данного прогона из локального
`artifacts/submission/tune-baseline-latest.json`. Все JSON, frozen labels,
predictions, manifest, `disagreements.private.json`, hashes и сырые результаты
остаются в игнорируемом `data/private/tune-baseline-*/`. В Git сохранена только
эта сводка безопасных агрегатов без case IDs, annotator, транскриптов, ключей,
аудиоссылок, промптов и текстов ответов модели.

В журнале проверены 45 starts / 45 completed / 0 retry, отсутствие ключа,
полных текстов реплик и URL. У исходных tune и holdout checksum не изменился;
предсказаний holdout нет. Точный финальный head, Q-01 и CI — в
[PR №8](https://github.com/abilkhayrbigali-design/HULKS_SIDE_family/pull/8).
