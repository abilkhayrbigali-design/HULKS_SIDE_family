Все файлы находятся в игнорируемом `data/private/benchmark-prep/`:

| `staging.json` | Проверенные API snapshots и fingerprints для группировки |
| `annotation-v1/README.md` | Краткое описание незаполненного пакета |

| `annotation-v1/cases/` | По одному читаемому Markdown на каждый диалог |
| `labels.working.json` | Отдельная рабочая копия для заполнения человеком |
| `working/tune/{RU,KZ,EN}.labels.json` | Раздельные настроечные файлы языковых аудиторов |
| `working/holdout/{RU,KZ,EN}.labels.json` | Раздельные файлы отложенной части |
| `working/{tune,holdout}/*.index.md` | Ссылки на читаемые кейсы соответствующего языка |

Пользователь подтвердил, что команда разметит набор по языкам. Для параллельной
работы используются шесть файлов в `working/`; общая копия сохраняется.
Файлы раздельных частей не пересекаются и вместе покрывают исходный пакет.
Имена реальных аудиторов и их ответы не подставлялись автоматически.

Draft имеет `annotation_source=pending_human`; ответы, применимость, объяснения,
evidence и annotator не заполнены. Он намеренно отклоняется benchmark.
Нельзя получить человеческий эталон одной заменой поля на `human`.
Условия завершения и правила каждого критерия — в [инструкции аудитора](ANNOTATION_GUIDE.md).

По Student Guide, стр. 1, DEV описан как 60 синтетических чатов и 5 реальных
звонков; подлинность аудио отдельно не проверялась. JSON сам не помечает
происхождение записей. Пять доступных звонков — RU, с готовыми транскриптами.
Проверка KZ/EN-звонков по этой выборке невозможна. Дикция, интонация и аудио-offset
по тексту не определяются; новых ASR-функций не добавляли.

  пагинация, фильтры, все пять звонков, исходные ISO timestamps, аудиоссылки,
  scroll/context и отсутствие фиктивного балла. Внешних, audio и изменяющих
  запросов, ошибок страницы и консоли — 0. Preview и Chromium остановлены.
- Генератор прошёл девять синтетических offline-проверок: транзитивные дубликаты,
  детерминизм при перестановке входа, редкая страта, произвольные критерии,

## Фиксация split и воспроизведение

Seed: `cqa-dev-split-v1-2026-11-08`; алгоритм:
`normalized-union-find_group-stratified-local-search-v1`, цель holdout около 30%.
Группы строятся транзитивно по Unicode NFKC/casefold/whitespace-нормализованной
последовательности speaker+text, fingerprint внешнего ID и непустой аудиоссылки.
Группа целиком принадлежит одной части. Подбор балансирует язык/канал;
неустранимые ограничения редких групп отражаются в manifest.
Близкие перефразировки требуют отдельной экспертной проверки: техническая
группировка не доказывает полной смысловой независимости диалогов.
