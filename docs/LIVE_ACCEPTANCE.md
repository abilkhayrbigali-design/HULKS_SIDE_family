## Стоимость

Проверены официальные [тарифы](https://developers.openai.com/api/docs/pricing)
и [страница GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)
2026-11-08: Standard short-context text input $0.10, cached input $0.01,
output $0.50 за миллион токенов.

Базовая оценка text-token части для этих четырёх вызовов:

```text
((7497 - 0) × $0.10 + 0 × $0.01 + 4428 × $0.50) / 1,000,000
= $0.0029637
```

Это **оценка по указанному Standard-тарифу, не подтверждённый счёт**. Приложение
не сохраняет service tier и отдельные cache-write counters; возможные cache-write,
региональные, tier/account-specific начисления и скидки не подтверждены.
Поэтому фактически выставленная полная стоимость неизвестна (`billed_total=null`),
а `provenance.estimated_cost_usd` приложения остаётся `null`. Тариф и допущения
записаны отдельно; неизвестные расходы не заменены нулём.

## Версии, доказательства и история

Все ответы прошли обычные проверки полноты критериев, шкал/N/A и существования
message/range IDs в зафиксированном транскрипте; итоги рассчитаны сервером.
У v2 инструкция контакта дополнена условием первой реплики оператора, вес изменён
с 10 на 20. Новая версия сохранена **через API** и выбрана четвёртым запуском;
v1 и её старые результаты остались неизменны. Редактор UI, включая добавление и
удаление критерия, отдельно проверен предыдущим offline backend E2E; этот факт
не переименован в живое редактирование через браузер.

После живой RU-оценки выполнена техническая апелляция с override бинарного
ответа. Это проверка пересчёта, не человеческая разметка: original 100.00
сохранён, final стал 84.62, revision=1. После остановки и нового запуска
приложения на той же отдельной БД original и история решения сохранились.
Апелляция и перезапуск новых OpenAI-вызовов не делали.

Сохранённый настоящий результат затем открыт Chromium через обычный HTTP-сервер
с **пустым ключом**: показаны `openai / gpt-6-luna`, итог, переход к доказательству
и результат после reload. Синтетический баннер отсутствует. Pageerrors и внешних
браузерных запросов — 0; дополнительных AI-вызовов — 0. Временный сервер остановлен.

## Команды и безопасные артефакты

Однократный локальный runner выполнен командой:

```bash
backend/.venv/bin/python /tmp/cqa_live_acceptance.py
node /tmp/cqa_live_readback.cjs
```

Это локальные приёмочные скрипты данной сессии, не файлы репозитория и не команды
новой установки. Приложение запускается обычными командами README. Повторять
однократный runner без необходимости не требуется: он выполняет платные вызовы.

Локальный ключ прочитан непосредственно из существующего серверного `.env` основной
копии и передан Settings в памяти. В новую копию или Git ключ не переносился.
Подписанный URL организаторов пуст; внешние данные не импортировались.
Отдельная БД, полные сохранённые оценки и агрегированный отчёт находятся только в
игнорируемом `data/private/live-smoke-*/`; указатель —
`artifacts/submission/live-latest.json`. В Git не добавлены эти файлы, тексты
диалогов/промптов/ответов, аудиоссылки, ключи или сырые HTTP-исключения.

Проверено отсутствие ключа, полных текстов синтетических реплик и URL в журнале
прогона. Использованы существующие события `cqa.evaluation/ai_request_started|completed`,
`cqa.worker/evaluation_completed`, `cqa.evaluation/appeal_decision_saved` и
`cqa.requests`; runner добавил фиксированные `cqa.live_smoke/live_smoke_completed|failed`
без payload. Непредвиденный сбой runner проходит через `log_internal_error`.
